# Reading Arc

Mi registro de lectura: biblioteca, pendientes con cola de siguientes, diario de sesiones, revisión de los domingos y balance.

- Web estática publicada con GitHub Pages.
- Datos e inicio de sesión en Supabase. Cada usuario solo puede leer y escribir sus propias filas (Row Level Security).
- `config.js` contiene la URL del proyecto y la clave pública (anon/publishable), que están pensadas para ir en el navegador.
- Portadas de Open Library en `covers/`.
